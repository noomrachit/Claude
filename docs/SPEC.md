สร้างเว็บแอปจัดการงานแบบคัมบัง (ทางเลือกแทน Trello) ด้วย React + TypeScript + Vite และ Supabase

## เทคโนโลยี
- ส่วนหน้า: React, TypeScript, Vite, Tailwind CSS, React Router
- ข้อมูลฝั่งเซิร์ฟเวอร์: TanStack Query
- ลากและวาง: dnd-kit
- ส่วนหลัง: Supabase (Postgres, Auth, Realtime, Storage)

## ฟีเจอร์หลัก (MVP)
1. สมัคร/เข้าสู่ระบบด้วยอีเมลและ Google ผ่าน Supabase Auth
2. บอร์ด: สร้าง แก้ไขชื่อ ลบ และเก็บเข้าคลัง
3. ลิสต์ในบอร์ด: เพิ่ม เปลี่ยนชื่อ ลบ ลากเรียงลำดับ
4. การ์ดในลิสต์: เพิ่ม แก้ไข ลบ ลากย้ายข้ามลิสต์ได้
5. รายละเอียดการ์ด: คำอธิบาย วันครบกำหนด ป้ายสี เช็คลิสต์ ผู้รับผิดชอบ ไฟล์แนบ
6. สมาชิกบอร์ด: เชิญด้วยอีเมล กำหนดบทบาท (เจ้าของ/แก้ไขได้/ดูอย่างเดียว)
7. อัปเดตแบบเรียลไทม์เมื่อสมาชิกคนอื่นแก้ไขบอร์ด
8. ค้นหาการ์ดและกรองตามป้ายสี/ผู้รับผิดชอบ

## ฐานข้อมูล
- ออกแบบตาราง: profiles, boards, board_members, lists, cards, labels, card_labels, checklist_items, attachments, comments
- ใช้คอลัมน์ position แบบ fractional indexing สำหรับเรียงลำดับ
- เขียนไฟล์ migration SQL ไว้ในโฟลเดอร์ supabase/migrations
- เปิด Row Level Security ทุกตาราง ให้เข้าถึงได้เฉพาะสมาชิกของบอร์ดนั้น
- ใส่ดัชนีที่จำเป็นและข้อมูลตัวอย่าง (seed)

## ประสบการณ์ใช้งาน
- ลากวางลื่นไหล อัปเดตหน้าจอทันทีแล้วค่อยซิงก์ (optimistic update) พร้อมย้อนกลับเมื่อผิดพลาด
- รองรับมือถือและโหมดมืด
- มีสถานะกำลังโหลด สถานะว่าง และข้อความแสดงข้อผิดพลาด

## โครงสร้างโค้ด
- แยกโฟลเดอร์: components, features (boards/lists/cards), hooks, lib/supabase, pages, types
- สร้างชนิดข้อมูล TypeScript จากสคีมา Supabase
- เก็บคีย์ใน .env และเขียน .env.example

## วิธีทำงาน
1. เสนอแผนสถาปัตยกรรมและสคีมาก่อน แล้วรอให้ฉันยืนยัน
2. ทำทีละขั้น: ตั้งค่าโปรเจกต์ → สคีมา+RLS → ระบบยืนยันตัวตน → บอร์ด → ลิสต์/การ์ด+ลากวาง → เรียลไทม์ → ส่วนเสริม
3. หลังแต่ละขั้น ให้รันตรวจชนิดข้อมูลและทดสอบ แล้วสรุปสั้นๆ ก่อนไปขั้นถัดไป
4. เขียน README อธิบายวิธีติดตั้ง ตั้งค่า Supabase และรันโปรเจกต์
